# VOID ONE · Montalvo Dynamics

Landing del VOID ONE y demo de la Mira S-01.

- Landing: `index.html`
- Mira S-01 (demo de visión por computadora, Chrome + cámara): `mira/`
  - Teclas: R registrar aliado · [ ] umbral · M espejo · C cámara · F pantalla completa · D diagnóstico · H ocultar ayuda
  - `mira/?prueba` abre una escena de prueba sin cámara.

Diseñado y fabricado en Cochabamba, Bolivia.
